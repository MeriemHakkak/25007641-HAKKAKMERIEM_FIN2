# Fiche du sujet F3 — Prévision de l'inflation

- **Thème** : prévision de l'inflation
- **Tâche** : régression sur séries mensuelles
- **Algorithmes possibles (support)** : 1, 2, 3, 6, 7, 16 — **vérifier dans ton support le numéro de Ridge / régression régularisée** ; si Ridge n'est pas dans cette liste, utiliser l'algorithme de régularisation de la liste (ex. n° 2) ou me le dire.
- **Algorithme retenu** : régression Ridge ; **alternatives** : MCO, forêt aléatoire.
